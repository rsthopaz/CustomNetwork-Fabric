# STEP 1 — Define Consortium / Network Blueprint

This is design-first, before generating any certificates or starting Docker.

Do not generate crypto yet.
Do not create containers yet.
Do not create channels yet.

First we define:

Who are the members of the blockchain?
What are their identities?
How many peers/orderers exist?
What naming convention is used?
What domains are used?

In Hyperledger Fabric, everything later depends on this naming, especially:

MSP IDs
certificate subjects
DNS names
container hostnames
channel consortium definitions
policy definitions

If this phase is messy → everything breaks later.
